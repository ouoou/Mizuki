# ER图

## 会员主数据 ER 图

```mermaid
erDiagram
    crm_retail_format_cf ||--o{ crm_member_md : "crm_retail_format_cf_id"

    crm_retail_format_cf {
        bigint id PK "ID"
        varchar name "名称"
        varchar code "编码"
        varchar rule_type "会员规则"
    }

    crm_member_md {
        bigint id PK "ID"
        varchar name "名称"
        varchar code "编码"
        varchar nickname "昵称"
        varchar phone "手机号"
        datetime birthday "生日"
        varchar gender "性别"
        bigint crm_retail_format_cf_id FK "关联业态"
        bigint gen_business_partner_md_id "关联合作伙伴"
    }
```

说明：

- `crm_member_md` 通过 `crm_retail_format_cf_id` 关联业态，一个业态下可以有多个会员主数据。
- `gen_business_partner_md_id` 指向合作伙伴主数据，但当前文档没有展开该表结构，所以没有在 ER 图里继续画出实体。

## 会员账户 ER 图

```mermaid
erDiagram
    crm_member_md ||--o{ crm_member_account_tr : "member_id"
    crm_retail_format_cf ||--o{ crm_member_account_tr : "retail_format_id"
    crm_member_account_type_cf ||--o{ crm_member_account_tr : "member_account_type_id"
    crm_retail_format_cf ||--o{ crm_member_account_type_cf : "retail_format_id"

    crm_member_md ||--o{ crm_member_account_ledger_tr : "member_id"
    crm_retail_format_cf ||--o{ crm_member_account_ledger_tr : "retail_format_id"
    crm_member_account_type_cf ||--o{ crm_member_account_ledger_tr : "member_account_type_id"
    crm_member_account_tr ||--o{ crm_member_account_ledger_tr : "target_member_account_id"

    crm_member_account_ledger_tr ||--o{ crm_member_account_ledger_details_tr : "member_account_ledger_id"
    crm_member_md ||--o{ crm_member_account_ledger_details_tr : "member_id"
    crm_retail_format_cf ||--o{ crm_member_account_ledger_details_tr : "retail_format_id"
    crm_member_account_type_cf ||--o{ crm_member_account_ledger_details_tr : "member_account_type_id"
    crm_member_account_tr ||--o{ crm_member_account_ledger_details_tr : "member_account_id"

    crm_retail_format_cf ||--o{ crm_member_account_task_tr : "retail_format_id"
    crm_member_account_type_cf ||--o{ crm_member_account_task_tr : "member_account_type_id"

    crm_member_md {
        bigint id PK "ID"
        varchar name "名称"
        varchar phone "手机号"
    }

    crm_retail_format_cf {
        bigint id PK "ID"
        varchar name "名称"
        varchar code "编码"
    }

    crm_member_account_type_cf {
        bigint id PK "ID"
        varchar name "会员账户类型名称"
        varchar code "会员账户类型编码"
        bigint retail_format_id FK "业态"
    }

    crm_member_account_tr {
        bigint id PK "ID"
        varchar member_account_status "会员账户状态"
        bigint available_amt "可用额度"
        bigint member_id FK "会员"
        bigint retail_format_id FK "业态"
        bigint member_account_type_id FK "会员账户类型"
    }

    crm_member_account_ledger_tr {
        bigint id PK "ID"
        varchar operate_type "操作类型"
        bigint change_amt "变更数额"
        varchar operate_flag "操作标记"
        bigint member_id FK "会员"
        bigint retail_format_id FK "业态"
        bigint member_account_type_id FK "会员账户类型"
        bigint target_member_account_id FK "目标会员账户"
    }

    crm_member_account_ledger_details_tr {
        bigint id PK "ID"
        varchar biz_code "业务编码"
        varchar operate_type "操作类型"
        bigint available_amt "可用额度"
        datetime expire_date "失效日期"
        bigint member_account_ledger_id FK "会员收支账目"
        bigint member_id FK "会员"
        bigint retail_format_id FK "业态"
        bigint member_account_type_id FK "会员账户类型"
        bigint member_account_id FK "目标会员账户"
    }

    crm_member_account_task_tr {
        bigint id PK "ID"
        varchar task_status "任务状态"
        varchar task_type "任务类型"
        bigint retail_format_id FK "业态"
        bigint member_account_type_id FK "会员账户类型"
    }
```

说明：

- 账户域核心是 `crm_member_account_tr`，它由 `会员 + 业态 + 账户类型` 共同约束。
- `crm_member_account_ledger_tr` 是账户流水主表，记录一次账户收支动作。
- `crm_member_account_ledger_details_tr` 是流水明细表，适合承载过期、拆分、来源追踪等更细粒度信息。
- `crm_member_account_task_tr` 更偏异步任务或补偿任务，不直接存账户余额，但会依赖业态和账户类型执行。

## 会员等级 ER 图

```mermaid
erDiagram
    crm_member_md ||--o{ crm_level_record_tr : "crm_member_md_id"
    crm_level_type_cf ||--o{ crm_level_record_tr : "crm_level_type_cf_id"
    crm_level_rule_cf ||--o{ crm_level_record_tr : "crm_level_rule_cf_id"

    crm_member_account_type_cf ||--o{ crm_level_type_cf : "crm_member_account_type_cf_id"
    crm_retail_format_cf ||--o{ crm_level_type_cf : "crm_retail_format_cf_id"
    crm_member_account_type_cf ||--o{ crm_level_rule_cf : "crm_member_account_type_cf_id"
    crm_level_type_cf ||--o{ crm_level_rule_cf : "crm_level_type_cf_crm_level_rule_cf_list_id"

    crm_member_md {
        bigint id PK "ID"
        varchar name "名称"
        varchar phone "手机号"
    }

    crm_retail_format_cf {
        bigint id PK "ID"
        varchar name "名称"
        varchar code "编码"
    }

    crm_member_account_type_cf {
        bigint id PK "ID"
        varchar name "会员账户类型名称"
        varchar code "会员账户类型编码"
    }

    crm_level_type_cf {
        bigint id PK "ID"
        varchar name "名称"
        varchar code "编码"
        varchar status "状态"
        datetime start_time "开始时间"
        bigint crm_member_account_type_cf_id FK "关联账户类型"
        bigint crm_retail_format_cf_id FK "关联业态"
    }

    crm_level_rule_cf {
        bigint id PK "ID"
        varchar desc "描述"
        bigint account_threshold "账户值门槛"
        bigint crm_member_account_type_cf_id FK "关联账户类型"
        bigint crm_level_type_cf_crm_level_rule_cf_list_id FK "关联等级类型"
        decimal level_protect_days "保级天数"
        bigint order_number "排序字段"
    }

    crm_level_record_tr {
        bigint id PK "ID"
        time level_change_date "等级变动时间"
        bigint crm_member_md_id FK "关联会员"
        bigint crm_level_type_cf_id FK "关联等级类型"
        bigint crm_level_rule_cf_id FK "关联等级规则"
    }
```

说明：

- `crm_level_type_cf` 是等级类型定义，通常描述某个业态下的等级体系。
- `crm_level_rule_cf` 是等级规则配置，按账户值门槛、保级天数等条件约束等级判定。
- `crm_level_record_tr` 是会员实际等级结果，关联会员、等级类型和命中的等级规则。
